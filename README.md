# EatWhat — Privacy Policy

This repository hosts the public privacy policy for the **EatWhat** iOS app
(a restaurant random-picker) via GitHub Pages.

**Live page:** https://qpan0831.github.io/eatwhat-privacy/

The page (`index.html`) is the privacy policy linked from the app's App Store
listing and shown in-app. The app's source code lives in a separate, private
repository.

## What the policy covers

- No account, no personal data collected by the developer.
- Location is used only while using the app, sent to the Google Places API to
  find nearby restaurants; not stored or linked to identity.
- No advertising or third-party analytics/tracking SDKs.
